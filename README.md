# National Accounts Statistics of India

## 📌 Overview

This dataset contains National Accounts Statistics data related to India's economic indicators across different years and industries.

## 🎯 Objectives

* Identify and handle missing values.
* Detect duplicate records.
* Clean and standardize data.
* Perform statistical analysis using Python.
* Visualize economic trends using graphs.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 📊 Expected Outcome

To produce a cleaned dataset and analyse economic indicators to identify patterns and trends.
